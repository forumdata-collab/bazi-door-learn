第1課

第一課：認識八字

🎯 學習目標

  • 理解八字命理的歷史背景與基本原理
  • 掌握天干、地支及六十甲子的概念
  • 了解四柱八字的組成結構

1. 八字的起源

八字命理是中國古代算命術的一種，始於漢，成於唐宋，盛於明清，至今不衰。八字是人出生的「時辰」，所以又叫「生辰八字」。人的出生時辰，紀以年、月、日、時，用以表述年月日時的叫做曆法。

📌 概念舉例

【淺白理解】「八字」就像身分證號碼：年月日時各配一組天干地支，四組共八個字，記錄了你出生那一刻的「時空坐標」。古人相信這個坐標能反映先天的性格與運勢。

2. 甲曆與干支

甲曆是甲子曆的簡稱，又稱干支曆。它由十個天干和十二個地支組成，一個天干輪配一個地支，天干在上，地支在下，一共配出六十個干支組合，用以紀年、紀月、紀日和紀時。生辰八字的年月日時以甲曆為紀，由六十組干支構成了年柱、月柱、日柱和時柱，所以八字算命又叫四柱算命。

3. 四柱結構

八字命盤由年月日時四柱共八個字構成。例如：年柱→丙申、月柱→甲午、日柱→己巳、時柱→庚午。每一柱由一個天干和一個地支組成，四柱共八個字，故稱「八字」。天干好比一棵大樹的枝和葉，反映了命主的外在和吉凶現象；地支則好比大樹的根，體現了命主的生命力和潛能。

第2課

第二課：天干地支

🎯 學習目標

  • 熟記十天干及其五行屬性
  • 熟記十二地支及其五行屬性
  • 掌握六十甲子的組成規律

1. 十天干

甲、乙、丙、丁、戊、己、庚、辛、壬、癸。天干配五行：甲乙屬木，丙丁屬火，戊己屬土，庚辛屬金，壬癸屬水。天干配陰陽：甲、丙、戊、庚、壬屬陽，乙、丁、己、辛、癸屬陰。

📌 概念舉例

【淺白理解】把十天干想像成十種性格標籤：甲是參天大樹（棟梁）、乙是花草藤蔓（柔韌）、丙是太陽（光明）、丁是燭火（細膩）……五行是底色，陰陽是明暗，組合成每個字獨特的屬性。

2. 十二地支

子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥。地支配五行：亥子屬水，寅卯屬木，巳午屬火，申酉屬金，辰戌丑未屬土。地支配陰陽：子寅辰午申戌為陽，丑卯巳未酉亥為陰。

3. 六十甲子

將一個天干和一個地支輪番配對，便可以配成六十甲子。先配第一輪：甲配子，乙配丑，丙配寅……癸配酉；再由甲配戌，乙配亥。六十甲子可分成五組：第一組由甲子開始，第二組由丙子開始，第三組由戊子開始，第四組由庚子開始，第五組由壬子開始。

第3課

第三課：排四柱

🎯 學習目標

  • 學會起年柱（以立春為界）
  • 學會起月柱（以節氣為界）
  • 學會起日柱（查萬年曆）
  • 學會起時柱（五鼠遁口訣）

1. 起年柱

年柱以立春（約國曆二月四日）為分界，非以農曆正月初一。例如，國曆二月三日出生，即使已過農曆新年，年柱仍屬上一年。一九四一年至一九七九年在香港出生的人，出生的月份又恰好是三月至十一月之內，他的出生時間大多數記以夏令時間，需注意撥慢一小時。

📌 概念舉例

【淺白理解】排四柱就像填一張「出生時間表」：年柱看立春（不是元旦！）、月柱看節氣（不是農曆初一！）、日柱查萬年曆、時柱用口訣推。記住「立春分年、節氣分月」就成功了一半。

2. 起月柱

月柱以節氣（節）為分界。一年十二個節氣，配十二地支。正月建寅，二月建卯，三月建辰……十二月建丑。月柱可用「五虎遁年起月」口訣推算：甲己之年丙作首，乙庚之歲戊為頭，丙辛歲首尋庚起，丁壬壬位順行流，戊癸何方發，甲寅之上好追求。

3. 起日柱

日柱需查萬年曆。日的分界以子時（晚上十一時）為準。注意「夜子時」問題——晚上十一時至十二時出生者，日柱可能有爭議。一種意見認為子時為日之交，晚上十一時便進入第二日；另一種意見認為過了十二時零分才算交入第二日。

4. 起時柱

時柱可用「五鼠遁日起時」口訣推算：甲己還加甲，乙庚丙子初，丙辛從戊起，丁壬庚子居，戊癸何方發，壬子是真途。一個時辰等於兩小時。子時——午夜十一時至一時，丑時——一時至三時，寅時——三時至五時，以此類推。

第4課

第四課：五行生剋

🎯 學習目標

  • 掌握五行（木火土金水）的基礎概念
  • 理解五行相生相剋的關係
  • 了解十二長生與五行旺衰

1. 五行基礎

五行：木、火、土、金、水。分陰陽兩類，配入十天干：甲—陽木（棟梁之材）、乙—陰木（生氣之木）、丙—陽火（太陽之氣）、丁—陰火（凡間之火）、戊—陽土（堤岸城牆）、己—陰土（田園之土）、庚—陽金（刀斧之金）、辛—陰金（珠玉之金）、壬—陽水（江河之水）、癸—陰水（雨露之水）。

📌 概念舉例

【淺白理解】五行相生像接力賽：木燒成火（木生火）、火燒成灰土（火生土）、土裡挖出礦（土生金）、礦融成水液（金生水）、水澆灌樹木（水生木）——循環不息。相剋像互相制衡：刀砍木（金剋木）、樹根裂土（木剋土）、土擋水（土剋水）、水滅火（水剋火）、火熔金（火剋金）。

2. 五行相生

相生順序：木生火、火生土、土生金、金生水、水生木。以任何一行為「我」，生我者為母（印），我生者為子（食傷）。例如以木為我，水生木（水是母/印），木生火（火是子/食傷）。

3. 五行相剋

相剋順序：木剋土、土剋水、水剋火、火剋金、金剋木。以任何一行為「我」，剋我者為官殺，我剋者為財才。例如以木為我，金剋木（金是官殺），木剋土（土是財才）。

4. 十二長生

十二長生：長生、沐浴、冠帶、臨官、帝旺、衰、病、死、墓、絕、胎、養。描述五行在不同階段的旺衰狀態。如甲木長生在亥，沐浴在子，冠帶在丑，臨官在寅，帝旺在卯……

第5課

第五課：十神體系

🎯 學習目標

  • 理解十神的定義與分類
  • 掌握比肩、劫財、食神、傷官等十神含義
  • 學會判斷自黨與異黨

1. 十神定義

十神是日元（日柱天干）與其他干支五行生剋關係的名稱：比肩、劫財（同我）、食神、傷官（我生）、正財、偏財（我剋）、正官、七殺（剋我）、正印、偏印（生我）。比肩與劫財的區別：比肩是同性相見（如甲見甲），劫財是異性相見（如甲見乙）。

📌 概念舉例

【淺白理解】十神是「以我為中心」看人際關係：生我的像父母（印）、我生的像子女（食傷）、剋我的像上司壓力（官殺）、我剋的像錢財資源（財）、同我的像兄弟朋友（比劫）。你站在日主的位置，看其他七個字跟你甚麼關係，就是十神。

2. 十神的意義

比肩：代表兄弟、朋友、競爭。劫財：代表異性兄弟、競爭對手。食神：代表才華、口福、子女（女命）。傷官：代表智慧、名譽、反叛。正財：代表穩定收入、妻星（男命）。偏財：代表意外之財、父星。正官：代表職位、權力、夫星（女命）。七殺：代表壓力、挑戰、權威。正印：代表學問、母星、保護。偏印：代表偏門學問、繼母。

3. 自黨與異黨

將十神分兩大派：自黨——同我（比肩、劫財）和生我（正印、偏印）；異黨——剋我（正官、七殺）、我剋（正財、偏財）、我生（食神、傷官）。身旺者以異黨為喜、自黨為忌；身弱者反之。

第6課

第六課：合化沖合

🎯 學習目標

  • 掌握天干五合的規則
  • 理解地支六合與六沖
  • 了解合化的條件與意義

1. 天干五合

甲己合化土、乙庚合化金、丙辛合化水、丁壬合化木、戊癸合化火。五合是陰陽之合，一個陰干配一個陽干，二者五行本來相剋，因陰陽相吸而由剋變合。合化條件：鄰干作合、月提引化、化神透干。

📌 概念舉例

【淺白理解】「合」像兩個人結婚——性格變了（甲己合化土），「沖」像兩個人吵架——天翻地覆（子午沖）。合化有條件：要鄰居（鄰干）、要媒人（月提引化）、要證婚（化神透干），三者齊備才成「化」。

2. 地支六合

子丑合化土、寅亥合化木、卯戌合化火、辰酉合金、巳申合化水、午未合火土。六合也是一陰支配一陽支，以方位對配而作合。合化條件：天干見化神透出方可成化。

3. 地支六沖

子午沖、丑未沖、寅申沖、卯酉沖、辰戌沖、巳亥沖。相沖的地支方位相對、五行剋戰。六沖代表動盪、變化、分離。如年柱受沖影響祖輩，月柱受沖影響父母，日柱受沖影響配偶，時柱受沖影響子女。

4. 合化的意義

合化後，原本的喜神可能變成忌神，原本的忌神也可能變成喜神。例如命局以金為喜，乙庚合化金，則乙木運可能由忌變喜。因此起盤算命之前，原局的干支合化一樣不能草率了事。

第7課

第七課：定格局

🎯 學習目標

  • 學會用三審法判斷身旺身弱
  • 理解正格與特格的區別
  • 掌握透干、得根、會局等判斷原則

1. 格局分類

八字格局只分兩大類：正格——局內有自黨又有異黨，日主不是身旺就是身弱；特格——局內全是自黨或全是異黨，日主極旺（專旺格）或極弱（從格）。

📌 概念舉例

【淺白理解】定身旺身弱就像量體溫：月令（審令）是體溫計，地支（審地）是床的軟硬，天干（審勢）是蓋的被子厚薄。三項量完，自黨（幫你的人）多就是身旺，異黨（消耗你的人）多就是身弱。

2. 三審法

定正格衰旺的基本法則叫「三審」：審令（月令）——日元生於自黨月令叫得令，生於異黨月令叫失令；審地（地支）——其餘三個地支自黨多叫得地；審勢（天干）——其餘三個天干自黨多叫得勢。三失其二以上為身弱。

3. 五個輔助原則

1. 透干原則：月令所藏天干透出天干者秉令。2. 得根原則：天干在地支重見謂之得根。3. 會局原則：地支會局成化，三支作同一神看。4. 貼身原則：貼住日元的坐支、時干、月干若是劫比印，其力直達日元。5. 夾剋原則：自黨遭鄰柱夾剋被剋死，身旺轉身弱。

第8課

第八課：用神體系

🎯 學習目標

  • 理解通關用神的概念與應用
  • 掌握調候用神的原理
  • 了解病藥用神的實戰意義

1. 通關用神

當命局兩行對峙、氣勢不通時，取通關之神使氣流通。例如：財才剋印，官殺是通關用神——因為財才生官殺，官殺生印，財才不剋印。又如：官殺剋劫比，印是通關用神——因為官殺生印，印生劫比，官殺不剋劫比。通關用神在歲運出現時，通常伴隨轉危為安、化險為夷的事情。

📌 概念舉例

【實例】某造身弱有印，原局天干財星剋印，印星孤露無助。當大運見官殺（如壬戌運），財生官殺，官殺生印，化解了財剋印的危機。此造交入官殺運後，自立門戶開設會計師事務所，正是「殺印相生」之應。

2. 調候用神

將十日主分做陰陽五行，以木火土金水五種物性，相對於它所生的月令氣候，作為喜用的依據。例如甲木生於冬令（亥月、子月），木寒要用火暖，丙就是調候用神。又如金生於夏令（巳月、午月），烈火熔金，就要用水調候，壬就是調候之神。

📌 概念舉例

【注意】調候用神深入民心，但卻容易捉錯用神。例如丁火弱命生於午火月，不單不忌火，凡見丙丁巳午火都會發大財。因為身弱得令，調候用神反而會誤判喜忌。

3. 病藥用神

八字命局以中和為貴。古書云：「有病方為貴。」所謂病，是指八字格局有「病」，缺五行是其中一種病。當歲運遇到「藥」的時候，病便會痊癒了。例如八字五行欠木，就是病，那麼木也就是藥了。當歲運見木（甲乙寅卯），那就是藥到病除的時候了。

📌 概念舉例

【應用】改名也可以用病藥原理。五行欠水，改個三點水的名字；五行欠金，改個金字旁的名字。另一種病是正格的身旺病或身弱病——身旺宜剋泄，異黨是藥；身弱宜幫扶，自黨是藥。

第9課

第九課：實戰論命

🎯 學習目標

  • 學會判斷好命與劣命的條件
  • 掌握富命與貧命的判斷方法
  • 理解吉凶斷法的基本原則

1. 好命條件

好命四條件：1. 五行中和——十神印劫傷財官樣樣都有；2. 秀氣流行——天干地支八字沿一個方向順或逆生下去；3. 用神有力——用神在天干透出且地支有根；4. 少剋沖刑伏合——四柱之間沒有太多衝突。

📌 概念舉例

【淺白理解】看一個八字好不好，先看四件事：五行齊不齊（中和）、能量順不順（秀氣流行）、用神強不強（用神有力）、衝突多不多（少剋沖刑）。四樣都好就是好命——但大富大貴反而常是五行不全的「特殊命格」，靠用神力挽狂瀾。

2. 富命與貧命

判斷原則：正格身旺以正財偏財代表財富；正格身弱以劫財比肩代表財富。專旺格以劫比代表財富；從格以財才代表財富。原局財星透干根強，歲運又見財星干支同氣，便是富命。原局不見財星，歲運又無財星運，便是貧命。

3. 吉凶斷法

《滴天髓》云：「何知其人吉，喜神為輔弼；何知其人凶，忌神輾轉攻。」喜神為輔弼——命局中要有喜神，而且要一輔一弼（兩個相鄰的喜神），才能發揮「制忌生喜」的作用。忌神輾轉攻——歲運忌神齊見，將喜神剋死時便凶。

4. 斷事要訣

六親：印代表母，財代表妻/父，官殺代表子女（男命），傷食代表子女（女命）。財運：身旺歲運財透有根主財至；身弱歲運劫比透有根主財至。婚姻：女命見官殺歲運緣至；男命見財才歲運緣至。健康：身弱再遇傷食財才重泄主慢性病；財生官殺重剋日主是血光手術。
